## 路线说明

这套课程覆盖机器视觉成像、数字图像、HALCON 基础、图像增强、分割、特征、形态学、标定、匹配和双目视觉。学习时不建议单纯按算子数量推进，而应始终围绕“稳定成像、提取目标、描述特征、建立坐标、输出结果”这条工程主线。

公开视频共包含 63 个分段。以下内容依据课程公开简介与分段目录重新组织，适合作为 HALCON 教程的导航地图，不是视频逐字稿。

## 第一阶段 机器视觉系统

先区分机器视觉与更广义的计算机视觉，再理解光源、镜头、相机和触发采集如何共同决定输入图像质量。

重点问题：

- 检测目标需要突出轮廓、颜色、纹理还是表面高低差。
- 视野、精度、景深、工作距离和节拍是否能同时满足。
- 曝光、运动和触发是否同步。
- 是否能通过成像设计减少后续算法复杂度。

## 第二阶段 数字图像与 HALCON 基础

数字图像基础包括图像分类、采样、量化、邻域、连通性、距离、区域、边界和直方图。进入 HALCON 后，需要建立三类核心对象的概念：图像、区域和 XLD 轮廓。

HALCON 入门还应掌握：

- 算子参数的输入、输出和控制参数。
- 图像获取、通道处理和颜色空间转换。
- Tuple、变量与基本控制语句。
- ROI 的交互生成和区域约束。
- 仿射变换、投影变换与图像插值。

```halcon
read_image (Image, 'part')
get_image_size (Image, Width, Height)
gen_rectangle1 (ROI, 0, 0, Height - 1, Width - 1)
reduce_domain (Image, ROI, ImageReduced)
```

## 第三阶段 图像增强

图像增强的目标是让后续分割与特征提取更稳定，而不是让图像“看起来更漂亮”。课程涉及灰度变换、平滑、锐化和频域处理。

| 方法 | 主要作用 | 风险 |
| --- | --- | --- |
| 灰度变换 | 调整亮度与对比度 | 饱和后细节无法恢复 |
| 平滑滤波 | 抑制随机噪声 | 边缘与小缺陷被削弱 |
| 图像锐化 | 强化灰度变化 | 同时放大噪声 |
| 频域处理 | 分离周期结构与频率成分 | 参数难以跨场景直接复用 |

增强操作必须通过后续检测指标评价。例如，为了提高阈值分割稳定性，可以接受少量纹理损失，但不能破坏目标边界。

## 第四阶段 图像分割与边缘

课程从全局手动阈值和局部阈值开始，继续扩展到 Canny 边缘、区域生长、分裂合并、Hough 变换和分水岭。

选择方法时可以先问：

1. 目标与背景是否存在稳定的灰度或颜色差异。
2. 需要的是像素区域，还是精确的亚像素边缘。
3. 目标是否粘连、遮挡或内部存在孔洞。
4. 要检测的是任意形状，还是直线、圆等参数化几何。

```halcon
threshold (Image, Region, 0, 96)
connection (Region, ConnectedRegions)
select_shape (ConnectedRegions, Selected, 'area', 'and', 500, 999999)
```

全局阈值适合照明均匀的高对比场景；局部阈值适合缓慢变化的背景；Canny 等边缘方法适合轮廓与测量；分水岭常用于拆分相互接触的目标。

## 第五阶段 特征提取

分割得到候选区域后，需要用特征描述和筛选目标。课程包括区域形状特征、基于灰度的特征和灰度共生矩阵纹理特征。

常见特征可以分为：

- 几何特征：面积、宽高、圆度、矩形度、方向和质心。
- 灰度特征：均值、方差、最小值、最大值和对比度。
- 纹理特征：能量、熵、相关性和同质性。

特征需要与缺陷机理对应。边缘缺口优先考虑轮廓和形状差异，表面粗糙度变化则更可能需要灰度或纹理特征。

## 第六阶段 形态学处理

形态学使用结构元素改变区域或灰度结构。课程覆盖腐蚀、膨胀、开闭运算、击中击不中、灰度形态学、顶帽底帽、孔洞填充和骨架。

| 运算 | 典型效果 |
| --- | --- |
| 腐蚀 | 收缩区域，去除细小连接 |
| 膨胀 | 扩张区域，连接邻近结构 |
| 开运算 | 去除小前景和细小凸起 |
| 闭运算 | 填补小缺口并连接近邻区域 |
| 顶帽 | 突出比背景更亮的小结构 |
| 底帽 | 突出比背景更暗的小结构 |

结构元素的形状和尺寸必须与物理缺陷尺寸、图像分辨率对应。半径过大会同时修改正常结构。

## 第七阶段 相机标定与视觉测量

相机标定建立像素坐标与实际几何之间的关系。课程从成像原理和几何模型出发，介绍径向畸变、切向畸变、DLT、张正友标定法以及 HALCON 标定助手。

测量项目要重点检查：

- 标定板覆盖范围是否包含实际测量区域。
- 标定图像的姿态变化是否充分。
- 镜头焦距、工作距离或相机位置改变后是否重新标定。
- 最终误差是否用真实量具和独立样本验证。

标定残差小并不自动等于现场测量准确，机械安装、景深、零件高度变化和边缘提取误差都会进入最终误差预算。

## 第八阶段 模板匹配与定位

课程介绍 NCC 模板匹配、不变矩特征、基于形状的模板匹配、Matching 助手和图像金字塔。

NCC 依赖灰度分布，适合外观相对稳定的目标；基于形状的匹配更关注边缘结构，对部分亮度变化通常更稳健。图像金字塔通过由粗到细的搜索提高速度，但过度降采样会丢失小目标特征。

定位结果通常包括行、列、角度和匹配分数。得到位姿后，可以通过仿射变换将检测 ROI 对齐到目标坐标系。

## 第九阶段 双目视觉与工程集成

最后阶段扩展到多视几何、双目立体视觉、分类分拣和码垛，并演示通过 HDevEngine、C++ 与 MFC 集成 HALCON 流程。

双目视觉通过两个视角的对应关系估计深度。实际系统不仅需要双目标定，还需要稳定的特征对应、合适的基线和足够的纹理信息。

工程集成时建议把算法封装为明确的输入输出接口：图像与配置进入，结构化检测结果返回。界面、相机通讯、结果存储和算法流程保持边界清晰，才能独立测试和替换。

## 推荐学习顺序

1. 先完成机器视觉系统与数字图像基础，理解图像从哪里来。
2. 学会 HALCON 图像、区域、XLD 和 ROI 的基本操作。
3. 用阈值、连通域和形状筛选完成第一个检测闭环。
4. 再学习增强、边缘、形态学和纹理特征，解决不稳定样本。
5. 进入标定、测量和模板匹配，建立坐标与定位能力。
6. 最后学习双目视觉及 C++、C# 或 Python 集成。

每完成一个阶段，都应保存正常样本、边界样本和失败样本，并记录参数变化对结果的影响。能解释失败原因，比记住更多算子更重要。
